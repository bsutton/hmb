# Tools

Open **Home → Tools** for these utilities:

| Tool | Current workflow |
| --- | --- |
| Painting | Select a room project and room, choose walls/ceiling, preparation grade and finish, then use Save and calculate. Copy estimate is available after calculation. Check dimensions and assumptions before using the result for a quote. |
| Trip log | Select a period, review trips and classify them. Review “Near job” matches rather than assuming they are correct. Settings control logging and route lookup; unknown road distances can be retried or reviewed. |
| Inventory | Maintain tool details, purchase information, serial-number photos and receipt photos. |
| Plasterboard | Create room projects and edit room outlines/layouts. Review sheet orientation, waste assumptions and the generated layout/Sheet Explorer before relying on quantities. PDF output is available. |
| Mailings | Create a mailing, review recipients and delivery information, then use the available label/route workflow. Check excluded customers and addresses. Maps actions can transfer address/route data to Google. |
| Job Report | Select a job, choose tasks and photos to include, then create and review the customer report. Report creation is separate from sending it. |

These tools do not replace reviewing the job's billing scope or recorded costs.
Location, Maps and delivery features depend on settings, permissions and service
configuration; see [Privacy and data flows](privacy.md) and [Settings](system.md).
