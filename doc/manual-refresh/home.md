# HMB

HMB (Hold My Beer) helps a solo tradesperson manage customers, jobs, tasks,
scheduling, estimates, quotes, time, materials and invoices on Android.

Start with a customer and job, add tasks, then use the parts of the workflow you
need: estimate, quote, schedule, shop, pack, record work and invoice. Tasks can
inherit the job's billing type or override it, allowing mixed billing within a job.

The dashboard gives access to Jobs, Today, shopping, packing, Accounting,
Customers, Suppliers, Tools, Backup and Settings. Use the Home button to return.
Booking Requests appears only when its integration is configured.

Core records are stored locally. Delivery, backups, photo sync and external
integrations need connectivity. Keep a recent off-device database backup and
sync photos separately; a database backup is not a substitute for photo sync.

Begin with [Getting Started](getting-started.md), [Tools](tools.md) and
[Backups](backups.md).
For help, use [issues](https://github.com/bsutton/hmb/issues) or
[discussions](https://github.com/bsutton/hmb/discussions).
