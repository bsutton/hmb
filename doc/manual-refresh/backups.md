# Backups

Keep a recent copy of your database off the device. Open **Home → Backup**, sign
in to the intended Google Drive account if needed, then choose **Backup**.
Check the success message and last successful backup time.

**Sync Photos** is separate and includes job, receipt and tool photos. Allow it
to finish and check for failures. Pending photo sync can also resume when the
app starts or resumes with authentication available. Database backup alone does not establish that
all photos have been copied.

**Backup Local** creates a local database copy; a copy left only on the same
phone does not protect against loss of the device. Drive operations require
connectivity. See [Restoring](restoring.md).
