# Restoring

Restoring replaces working data with the selected backup. Preserve a current
backup first if you may need the current records.

Open **Home → Backup → Restore**, sign in to the intended Google Drive account
if prompted and select the required backup. Follow the app's prompts and check
the result before returning to work. Do not rely on a fixed completion time.

Verify recent customers, jobs and invoices, photo availability, and integration
configuration after restore. Device-held credentials may need to be entered or
authorized again. Database backup and photo sync are separate operations.
