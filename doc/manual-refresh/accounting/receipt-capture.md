# Receipt Capture

Open **Accounting → Receipts** and add a receipt. The current editor has steps
for **Capture**, **Receipt Lines**, **Totals**, **Job Cost Allocation** and
**Task Item Links**.

Record the supplier, date and primary job when applicable. Capture the receipt
image, review or add line items, then check totals and tax treatment. If using
extraction, review the extracted values against the receipt before saving.

Costs can be allocated across jobs. Receipt lines can be matched to task items;
review and confirm suggested matches instead of treating them as final.
**Use Line Totals** helps reconcile header totals with entered lines.

A receipt records an expense; it is not a customer payment. Recording a receipt
also does not by itself prove every associated material has been billed. Use
Materials Billing and Unlinked Costs reports to review gaps.
