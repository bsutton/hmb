# Quoting

Build the job estimate using tasks and task items, then create a fixed-price quote
for eligible fixed-price tasks. A job can mix fixed-price and T&M tasks; T&M work
is not included in the fixed-price quote merely because it shares the job.

Review the quote's scope, charges, contact and PDF before sending. Use the quote
lifecycle actions to record approval, rejection, withdrawal or a supported
revision/amendment. Sending a quote does not approve it.

Approval matters for invoicing: quoted fixed-price scope needs approval, and
milestones govern invoicing when present. Work added outside the quote remains
separate unless included through the quote workflow.

Set business/contact details and PDF branding under **Settings → Business,
Contact and Billing**. See [Estimating a job](quotes-estimates/estimating-a-job.md)
and [Fixed Price invoicing](invoicing/fixed-price.md).
