# Time and Materials / Cost Plus

Record time against tasks and record material quantities and actual costs.
Complete the relevant task items so eligible unbilled items can be selected for
invoicing. Labour billing uses time entries; Labour task items are for fixed-price
estimating and are not the way to record T&M labour.

You can invoice progressively. Review the selected tasks, labour grouping and
materials before creating each draft. Already billed work is excluded from a
subsequent invoice unless a supported correction releases it for billing.
Add new items for additional purchases rather than modifying billed history.

The booking fee is a once-per-job charge; review the **Bill booking Fee** option
and the invoice history. Set the job's fee to zero if no fee is agreed.

Use the invoice's supported correction actions instead of assuming deletion is
always available. Creating an invoice is separate from completing the job.
