# Xero

Open **Settings → Integrations → Xero**. The current form includes:

- Enable Xero Integration
- Xero Client ID and Xero Client Secret
- Invoice Line Revenue Account Code
- Invoice Line Inventory Item Code

The revenue account and inventory item codes must exist in Xero. Obtain valid
credentials and configure the connection for your organisation; this guide does
not establish which current Xero subscription or developer plan is sufficient.
Save the settings and complete the relevant authorization when using the service.

Review the invoice's stored billing contact and email address before uploading.
When external accounting is enabled, invoice email requires a successful upload.
Use **Accounting → Sync** to refresh external payment status and inspect any
sync warning. Correct external records in the appropriate accounting workflow;
HMB's local payment actions depend on how that invoice is managed.

No live upload, authorization or payment synchronization was performed during
this documentation review.
