# Jobs

A job groups work for a customer. Add a job from **Home → Jobs**, select the
customer, and choose the site and contacts needed for the work. Save the job
before adding tasks. A useful example is “Repair garden gate”, with separate
tasks for replacing hinges and painting.

Choose **Fixed Price**, **Time and Materials**, or **Non-billable**. This is a
default for tasks; each task can override it. A mixed job can contain both quoted
fixed-price work and separately invoiced time-and-materials work.

Review the hourly rate and booking fee. Defaults can come from Settings → Billing
or the customer, with job-specific values taking precedence.

Contacts have different purposes: the person organising work need not be the
person receiving the invoice. Review the billing contact when creating an invoice.
Changing a job contact does not silently rewrite an existing invoice's contact.

Use tasks for instructions, items, photos, estimates and tracked time. Use
[quotes](accounting/quoting.md) for fixed-price scope and
[invoices](accounting/invoicing.md) for eligible work. New work outside a quote
can be represented by additional tasks; a new job is not always required.
