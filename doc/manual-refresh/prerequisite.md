# Prerequisites

The Android build requires Android 11 or later. Obtain the current installation
or testing invitation from the HMB maintainer. Availability in a particular Play
Store testing track must be confirmed with the maintainer.

Other platform folders in the source repository do not establish supported
production releases. These instructions target the Android workflow.

Enter your business, contact and billing details before sending customer PDFs.
Google Drive backup and photo sync require a Google account and connectivity.
External accounting, SMTP email and other optional integrations each need their
own configuration. Core job records can be used offline.
