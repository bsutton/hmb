# Packing List

Open Packing from the home dashboard. The list is built from task items marked
**Tools - own**, **Materials - stock** and **Consumables - stock**. Use filters
to narrow the work you are preparing for, then mark items packed as you load them.

Buying and packing are different operations: items to purchase belong in the
Shopping list. Review the task item type if an expected item is missing.

Use **Add** to create a packing item. Quantity starts at **1** and cost at
**$0.00**; both can be changed before saving. Editing an existing item retains
its saved quantity and cost.
